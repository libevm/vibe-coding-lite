ツール

ワークフローで使う価値のあるもの。

ブラウザ自動化

  • Agent Browser — VercelによるオープンソースのAIエージェントブラウザ。エージェントが自律的にWebを閲覧、クリック、入力、ナビゲートできます。

インテグレーション

  • gogcli — Google Workspace CLI。Gmail、カレンダー、ドライブ、連絡先 — ターミナルから直接。
    • OAuthの設定が面倒なら Gaskill を使いましょう。APIキー1つで完了。このサイトの作者が作りました。

Durable Workflows

  • Absurd — Postgresネイティブの耐久性あるワークフローシステム。PostgreSQLにおける durable execution を中心に構築されています。

ドキュメント

  • qmd — CLIドキュメント検索エンジン。ターミナルからどのドキュメントサイトでも検索。シングルバイナリ。

エージェント拡張

  • pi-extensions — Piコーディングエージェント用の拡張機能とスキルのコレクション。ファイルブラウザ、タブステータス、長時間タスクループ、使用量ダッシュボードなど。

Vibe Coding Lite — 無料でオープンソースの vibe coding ガイド。登録不要、余計なものなし。
