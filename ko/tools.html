도구

워크플로에서 자리를 차지할 만한 도구들.

브라우저 자동화

  • Agent Browser — Vercel의 오픈소스 AI 에이전트 브라우저. 에이전트가 자율적으로 웹을 보고, 클릭하고, 입력하고, 탐색할 수 있습니다.

통합

  • gogcli — Google Workspace CLI. Gmail, 캘린더, 드라이브, 연락처 — 터미널에서 직접.
    • OAuth 설정이 귀찮다면 Gaskill을 사용하세요. API 키 하나면 끝. 이 사이트의 제작자가 만들었습니다.

Durable Workflows

  • Absurd — Postgres 네이티브 영속 워크플로 시스템. PostgreSQL에서의 durable execution을 중심으로 구축되었습니다.

문서

  • qmd — CLI 문서 검색 엔진. 터미널에서 모든 문서 사이트를 검색. 단일 바이너리.

에이전트 확장

  • pi-extensions — Pi 코딩 에이전트용 확장 및 스킬 모음. 파일 브라우저, 탭 상태, 장기 작업 루프, 사용량 대시보드 등.

Vibe Coding Lite — 무료 오픈소스 vibe coding 가이드. 가입 없음, 허튼소리 없음.
