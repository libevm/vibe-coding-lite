오픈소스 최고의 스타일 가이드를 가져오세요

TigerBeetle의 Tiger Style은 오픈소스에서 가장 엄격하고 잘 작성된 코딩 스타일 가이드 중 하나입니다. 주관이 뚜렷하고, 철저하며, 실전에서 검증되었습니다.

Zig를 사용하지 않아도 이점을 얻을 수 있습니다. Tiger Style을 여러분이 사용하는 언어의 관용구와 함께 AI 에이전트에게 전달하고, 새로운 코드 스타일 문서를 작성해 달라고 하세요. Tiger Style의 엄격함을 갖추면서도 여러분의 스택에 맞게 조정된 스타일 가이드를 얻을 수 있습니다.

Read this code style guide:
https://github.com/tigerbeetle/tigerbeetle/blob/main/docs/TIGER_STYLE.md

Now write a new code style document for [LANGUAGE] that captures the same
rigor, structure, and clarity — adapted to [LANGUAGE]'s idioms, ecosystem,
and best practices.

[LANGUAGE]를 사용 중인 언어로 바꾸세요. AI가 Tiger Style의 최고의 아이디어 — 네이밍, 에러 처리, 어설션, 단순성 — 를 여러분의 언어에 맞는 관례로 녹여낼 것입니다.
