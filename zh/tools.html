工具

值得在工作流中占一席之地的工具。

浏览器自动化

  • PinchTab — 通过 DevTools Protocol 连接真实 Chrome 实例的高性能桥接工具。无需 Puppeteer/Playwright。

集成

  • gogcli — Google Workspace 命令行工具。Gmail、日历、云盘、通讯录——直接从终端操作。
    • 或者使用 Gaskill，无需配置 OAuth。一个 API key 就够了。由本站作者开发。

文档

  • qmd — 命令行文档搜索引擎。从终端查询任何文档站点。单个二进制文件。

Vibe Coding Lite — 免费开源的 vibe coding 指南。无需注册，没有废话。

GitHub · @libevm
