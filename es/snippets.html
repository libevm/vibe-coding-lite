Roba la Mejor Guía de Estilo del Open Source

Tiger Style de TigerBeetle es una de las guías de estilo de código más rigurosas y bien escritas del open source. Es opinionada, exhaustiva y probada en batalla.

No necesitas usar Zig para beneficiarte. Dale Tiger Style a tu agente de IA junto con las convenciones de tu lenguaje, y pídele que escriba un nuevo documento de estilo de código. El resultado es una guía de estilo con el rigor de Tiger Style, adaptada a tu stack.

Read this code style guide:
https://github.com/tigerbeetle/tigerbeetle/blob/main/docs/TIGER_STYLE.md

Now write a new code style document for [LANGUAGE] that captures the same
rigor, structure, and clarity — adapted to [LANGUAGE]'s idioms, ecosystem,
and best practices.

Reemplaza [LANGUAGE] con el lenguaje en el que estés construyendo. La IA cruzará las mejores ideas de Tiger Style — nombres, manejo de errores, aserciones, simplicidad — en convenciones que se sientan nativas de tu lenguaje.
