Herramientas

Cosas que se ganan su lugar en el flujo de trabajo.

Automatización de Navegador

  • PinchTab — Puente de alto rendimiento a instancias reales de Chrome vía DevTools Protocol. Sin necesidad de Puppeteer/Playwright.

Integraciones

  • gogcli — CLI para Google Workspace. Gmail, Calendar, Drive, Contactos — directo desde la terminal.
    • O usa Gaskill si no quieres configurar OAuth. Una API key y listo. Creado por el autor de este sitio.

Documentación

  • qmd — Motor de búsqueda CLI para documentación. Consulta cualquier sitio de docs desde la terminal. Un solo binario.

Extensiones de Agente

  • pi-extensions — Colección de extensiones y skills para el agente de código Pi. Explorador de archivos, estado de pestañas, bucles de tareas largas, panel de uso y más.

Vibe Coding Lite — una guía gratuita y de código abierto. Sin registro, sin complicaciones.
